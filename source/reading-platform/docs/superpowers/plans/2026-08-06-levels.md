# Уровни вместо классов — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить «класс» на «уровень», где один уровень — это одна книга, уровень открывается после прохождения предыдущего, а учитель назначает книгам уровни и удобно управляет книгой из десятков частей.

**Architecture:** Добавляющая SQL-миграция (`books.level`, `students.start_level`) поверх живой базы, чистая функция открытия уровней в `src/lib/progress/levelUnlock.ts`, пакетная загрузка прогресса в `src/lib/db/`, затем перенос UI ученика и учителя на новые поля.

**Tech Stack:** Next.js 16 (App Router, server actions), React 19, TypeScript, Supabase (supabase-js через REST), vitest, CSS Modules.

## Global Constraints

- **Язык интерфейса — казахский.** Все новые видимые строки на казахском. Комментарии в коде — на русском, как в существующем коде.
- **Подпись уровня — ровно `N-деңгей`** (например `3-деңгей`). Функция `levelLabel`.
- **Заголовок пустой части при массовом создании — ровно `K-бөлім`**, где K — порядковый номер части.
- **База боевая:** 4 книги, 68 частей, 21 ученик, 88 попыток. Названия книг, тексты частей, вопросы, попытки, ответы и оценки не изменяются ни одним шагом плана.
- **Миграции применяются вручную** через SQL Editor в панели Supabase — CLI `supabase` и `psql` в окружении нет.
- **Проверки:** `npm test` (vitest), `npm run lint`, `npm run build` — все три должны быть зелёными в конце каждой задачи.
- **Переменные окружения** читаются из `.env.local`: `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.
- Импорты внутри `src` — через алиас `@/` (см. `tsconfig.json`).

`supabase/migrations/0003_levels.sql`:

```sql
-- Уровни вместо классов. Один уровень — одна книга.
--
-- Миграция ДОБАВЛЯЮЩАЯ: старые колонки grade остаются на месте, чтобы
-- работающая версия сайта не сломалась между применением SQL и выкатом кода.
-- Их удаляет отдельная миграция 0004, которую запускают позже.

-- Книга получает уровень, равный её прежнему классу.
alter table books add column if not exists level int;
update books set level = grade where level is null;
alter table books alter column level set not null;
alter table books add constraint books_level_key unique (level);

-- Стартовый уровень ученика: с него он начинает лестницу.
-- Все начинают с первого уровня — прежний класс не переносится (решение
-- владельца платформы). Пройденные части при этом никуда не деваются:
-- дойдя до своего уровня заново, ученик увидит их уже отмеченными.
-- Учитель может поднять стартовый уровень любому на странице «Оқушылар».
alter table students add column if not exists start_level int not null default 1;

-- Таблица доступов осталась от первой версии и никогда не использовалась.
drop table if exists enrollments;

create index if not exists idx_books_level on books(level);

grant all on all tables in schema public to anon, authenticated, service_role;
```

import { unlockedThroughLevel, isLevelUnlocked, type LevelBook } from "@/lib/progress/levelUnlock";
import type { PartStatus } from "@/lib/types";

// Книга уровня `level` с частями p{level}-1 … p{level}-{count}
function book(level: number, count: number): LevelBook {
  return {
    level,
    partIds: Array.from({ length: count }, (_, i) => `p${level}-${i + 1}`),
  };
}

// Статусы: перечисленные части completed, остальные not_started
function statuses(books: LevelBook[], completed: string[]): Map<string, PartStatus> {
  const m = new Map<string, PartStatus>();
  for (const b of books) {
    for (const id of b.partIds) {
      m.set(id, completed.includes(id) ? "completed" : "not_started");
    }
  }
  return m;
}

describe("unlockedThroughLevel", () => {
  const all = [book(1, 2), book(2, 2), book(3, 2), book(4, 2)];

  it("открывает уровни до стартового включительно", () => {
    expect(unlockedThroughLevel(all, 3, statuses(all, []))).toBe(3);
  });

  it("открывает следующий уровень, когда стартовый пройден целиком", () => {
    const done = statuses(all, ["p3-1", "p3-2"]);
    expect(unlockedThroughLevel(all, 3, done)).toBe(4);
  });

  it("не открывает следующий, пока пройдена лишь часть книги", () => {
    const done = statuses(all, ["p3-1"]);

  it("не считает пройденной часть на проверке у учителя", () => {

    const done = statuses(all, ["p1-1", "p1-2", "p2-1", "p2-2"]);
    expect(unlockedThroughLevel(all, 1, done)).toBe(3);

  it("пустая книга не открывает следующий уровень", () => {
    const books = [book(1, 0), book(2, 2)];

`src/lib/progress/levelUnlock.ts`:

```ts
import type { PartStatus } from "@/lib/types";

// Книга в лестнице уровней: её уровень и идентификаторы частей.
export interface LevelBook {
  level: number;
  partIds: string[];
}

// До какого уровня включительно ученику открыт доступ.
//
// Стартовый уровень задаёт учитель — с него ученик и начинает, поэтому те,
// кто уже читал книгу «своего класса», ничего не теряют. Дальше лестница
// идёт вверх: пройденная целиком книга открывает следующую.
//
// Книга без частей пройденной не считается — иначе пустой уровень,
// который учитель ещё не наполнил, открывал бы всё за собой.
export function unlockedThroughLevel(
  books: LevelBook[],
  startLevel: number,
  statusById: Map<string, PartStatus>,
): number {
  const byLevel = new Map<number, LevelBook>();
  for (const b of books) byLevel.set(b.level, b);

  let through = startLevel;
  // Шагов не больше, чем книг: защита от зацикливания на кривых данных.
  for (let i = 0; i < books.length; i++) {
    const current = byLevel.get(through);
    if (!current || current.partIds.length === 0) break;
    const done = current.partIds.every(
      (id) => statusById.get(id) === "completed",
    );
    if (!done) break;
    through += 1;
  }
  return through;
}

export function isLevelUnlocked(level: number, unlockedThrough: number): boolean {
  return level <= unlockedThrough;
}
```

import { listBooks } from "@/lib/db/books";
import { unlockedThroughLevel, isLevelUnlocked } from "@/lib/progress/levelUnlock";
import type { PartStatus } from "@/lib/types";

export interface LevelEntry {
  book: Book;
  progress: BookProgress;
  unlocked: boolean;
}

// Все книги-уровни по возрастанию с прогрессом ученика и признаком доступа.
// Грузим все части сразу (их десятки, не тысячи): четыре пакетных запроса
// вместо запроса на книгу.
export async function levelsWithProgress(
  studentId: string, startLevel: number,
): Promise<LevelEntry[]> {
  const books = await listBooks();
  if (books.length === 0) return [];

  const db = createServerSupabase();
  const { data: partRows, error } = await db.from("parts")
    .select("*").in("book_id", books.map((b) => b.id)).order("order");
  if (error) throw error;
  const parts = ((partRows ?? []) as PartRow[]).map(partFromRow);

  const data = await loadPartData(studentId, parts.map((p) => p.id));

  const partsByBook = new Map<string, Part[]>();
  for (const p of parts) {
    const arr = partsByBook.get(p.bookId);
    if (arr) arr.push(p);
    else partsByBook.set(p.bookId, [p]);
  }

  const statusById = new Map<string, PartStatus>();
  for (const p of parts) statusById.set(p.id, statusFor(p.id, data));

  const through = unlockedThroughLevel(
    books.map((b) => ({
      level: b.level,
      partIds: (partsByBook.get(b.id) ?? []).map((p) => p.id),
    })),
    startLevel,
    statusById,
  );

  return books.map((book) => ({
    book,
    progress: bookProgressFrom(partsByBook.get(book.id) ?? [], data),
    unlocked: isLevelUnlocked(book.level, through),
  }));
}

export async function isBookUnlockedForStudent(
  studentId: string, startLevel: number, bookId: string,
): Promise<boolean> {
  const levels = await levelsWithProgress(studentId, startLevel);
  return levels.some((l) => l.book.id === bookId && l.unlocked);
}

export async function createBook(input: { title: string; description: string }): Promise<Book> {
  const db = createServerSupabase();
  const level = await nextBookLevel();
  const { data, error } = await db.from("books")
    .insert({ title: input.title, description: input.description, level })
    .select("*").single();
  if (error) throw error;
  return bookFromRow(data);
}

export async function updateBook(id: string, input: { title: string; description: string }): Promise<void> {
  const db = createServerSupabase();
  const { error } = await db.from("books").update(input).eq("id", id);
  if (error) throw error;
}

export async function nextBookLevel(): Promise<number> {
  const books = await listBooks();
  return books.length === 0 ? 1 : Math.max(...books.map((b) => b.level)) + 1;
}

// books.level уникален, поэтому обмен двух значений в лоб нарушил бы
// ограничение на промежуточном шаге. Меняем через свободное временное
// значение -1: уровни всегда положительные, столкнуться не с чем.
export async function swapBookLevels(idA: string, idB: string): Promise<void> {
  const db = createServerSupabase();
  const { data, error } = await db.from("books").select("id, level").in("id", [idA, idB]);
  if (error) throw error;
  const a = (data ?? []).find((r) => r.id === idA);
  const b = (data ?? []).find((r) => r.id === idB);
  if (!a || !b) return;

  const steps = [
    db.from("books").update({ level: -1 }).eq("id", idA),
    db.from("books").update({ level: a.level }).eq("id", idB),
    db.from("books").update({ level: b.level }).eq("id", idA),
  ];
  for (const step of steps) {
    const { error: stepError } = await step;
    if (stepError) throw stepError;
  }
}

// Назначение уровня книге. Если уровень занят — книги меняются местами:
// учитель не должен разбираться с ошибкой «уровень занят».
export async function setBookLevel(bookId: string, level: number): Promise<void> {
  const books = await listBooks();
  const target = books.find((b) => b.id === bookId);
  if (!target || target.level === level) return;

  const occupant = books.find((b) => b.level === level);
  if (occupant) {
    await swapBookLevels(bookId, occupant.id);
    return;
  }
  const db = createServerSupabase();
  const { error } = await db.from("books").update({ level }).eq("id", bookId);
  if (error) throw error;
}

export async function moveBookLevel(bookId: string, direction: "up" | "down"): Promise<void> {
  const books = await listBooks(); // уже отсортированы по level
  const i = books.findIndex((b) => b.id === bookId);
  if (i === -1) return;
  const j = direction === "up" ? i - 1 : i + 1;
  if (j < 0 || j >= books.length) return;
  await swapBookLevels(bookId, books[j].id);
}

// Массовое создание пустых частей: учитель сначала делает каркас книги
// на N глав, а тексты и вопросы вписывает потом.
export async function createParts(bookId: string, count: number): Promise<void> {
  const safeCount = Math.min(50, Math.max(1, Math.trunc(count)));
  const start = await nextPartOrder(bookId);
  const rows = Array.from({ length: safeCount }, (_, i) => ({
    book_id: bookId,
    order: start + i,
    title: `${start + i}-бөлім`,
    reading_text: "",
  }));
  const db = createServerSupabase();
  const { error } = await db.from("parts").insert(rows);
  if (error) throw error;
}

// (book_id, order) уникальна — обмен идёт через свободное временное
// значение -1, как и у уровней книг.
export async function swapPartOrder(idA: string, idB: string): Promise<void> {
  const db = createServerSupabase();
  const { data, error } = await db.from("parts").select("id, order").in("id", [idA, idB]);
  if (error) throw error;
  const a = (data ?? []).find((r) => r.id === idA);
  const b = (data ?? []).find((r) => r.id === idB);
  if (!a || !b) return;

  const steps = [
    db.from("parts").update({ order: -1 }).eq("id", idA),
    db.from("parts").update({ order: a.order }).eq("id", idB),
    db.from("parts").update({ order: b.order }).eq("id", idA),
  ];
  for (const step of steps) {
    const { error: stepError } = await step;
    if (stepError) throw stepError;
  }
}

export async function movePart(
  partId: string, bookId: string, direction: "up" | "down",
): Promise<void> {
  const parts = await listParts(bookId); // уже отсортированы по order
  const i = parts.findIndex((p) => p.id === partId);
  if (i === -1) return;
  const j = direction === "up" ? i - 1 : i + 1;
  if (j < 0 || j >= parts.length) return;
  await swapPartOrder(partId, parts[j].id);
}

export async function countQuestionsByPart(partIds: string[]): Promise<Map<string, number>> {
  const counts = new Map<string, number>();
  if (partIds.length === 0) return counts;
  const db = createServerSupabase();
  const { data, error } = await db.from("questions").select("part_id").in("part_id", partIds);
  if (error) throw error;
  for (const r of (data ?? []) as { part_id: string }[]) {
    counts.set(r.part_id, (counts.get(r.part_id) ?? 0) + 1);
  }
  return counts;
}

import { createServerSupabase } from "@/lib/supabase/client";
import { listBooks } from "@/lib/db/books";
import { listStudents } from "@/lib/db/students";
import { partFromRow, questionFromRow } from "@/lib/db/mappers";
import { computePartStatus } from "@/lib/progress/partStatus";
import { computeBookProgress, type BookProgress } from "@/lib/progress/bookProgress";
import { unlockedThroughLevel, isLevelUnlocked } from "@/lib/progress/levelUnlock";
import type { Answer, Book, Part, PartStatus, Question, Student } from "@/lib/types";
import type { AnswerRow, PartRow, QuestionRow } from "@/lib/db/rowTypes";

export interface OverviewRow {
  student: Student;
  unlockedThrough: number;
  books: { book: Book; progress: BookProgress }[];
}

function answerFromRow(r: AnswerRow): Answer {
  return {
    questionId: r.question_id,
    selectedOptionIndex: r.selected_option_index,
    textAnswer: r.text_answer,
    graded: r.graded,
    awardedPoints: r.awarded_points,
    teacherComment: r.teacher_comment,
  };
}

function partScore(questions: Question[], answers: Answer[]): number {
  return answers.reduce((sum, a) => {
    const q = questions.find((qq) => qq.id === a.questionId);
    if (!q) return sum;
    if (q.type === "open") return sum + (a.awardedPoints ?? 0);
    return sum + (a.selectedOptionIndex === q.correctOptionIndex ? q.points : 0);
  }, 0);
}

// Обзор учителя: раньше на каждую пару «ученик × книга» шло по три запроса
// (при 21 ученике — десятки, а с полным списком книг было бы под 250).
// Здесь пять запросов на всю страницу, остальное считается в памяти:
// частей и попыток в базе десятки, объём данных ничтожный.
export async function overviewRows(): Promise<OverviewRow[]> {
  const db = createServerSupabase();
  const [students, books] = await Promise.all([listStudents(), listBooks()]);
  if (students.length === 0 || books.length === 0) {
    return students.map((student) => ({
      student, unlockedThrough: student.startLevel, books: [],
    }));
  }

  const { data: partRows, error: partErr } = await db.from("parts")
    .select("*").in("book_id", books.map((b) => b.id)).order("order");
  if (partErr) throw partErr;
  const parts = ((partRows ?? []) as PartRow[]).map(partFromRow);

  const partIds = parts.map((p) => p.id);
  const [
    { data: qRows, error: qErr },
    { data: attemptRows, error: aErr },
  ] = await Promise.all([
    db.from("questions").select("*").in("part_id", partIds),
    db.from("attempts").select("id, student_id, part_id").in("part_id", partIds),
  ]);
  if (qErr) throw qErr;
  if (aErr) throw aErr;

  const attempts = (attemptRows ?? []) as { id: string; student_id: string; part_id: string }[];
  const answersByAttempt = new Map<string, Answer[]>();
  if (attempts.length > 0) {
    const { data: ansRows, error: ansErr } = await db.from("answers")
      .select("*").in("attempt_id", attempts.map((a) => a.id));
    if (ansErr) throw ansErr;
    for (const r of (ansRows ?? []) as AnswerRow[]) {
      const arr = answersByAttempt.get(r.attempt_id);
      if (arr) arr.push(answerFromRow(r));
      else answersByAttempt.set(r.attempt_id, [answerFromRow(r)]);
    }
  }

  const questionsByPart = new Map<string, Question[]>();
  for (const r of (qRows ?? []) as QuestionRow[]) {
    const q = questionFromRow(r);
    const arr = questionsByPart.get(q.partId);
    if (arr) arr.push(q);
    else questionsByPart.set(q.partId, [q]);
  }

  const partsByBook = new Map<string, Part[]>();
  for (const p of parts) {
    const arr = partsByBook.get(p.bookId);
    if (arr) arr.push(p);
    else partsByBook.set(p.bookId, [p]);
  }

  // Ответы ученика по частям: студент → часть → ответы.
  const byStudent = new Map<string, Map<string, Answer[]>>();
  for (const a of attempts) {
    let perPart = byStudent.get(a.student_id);
    if (!perPart) {
      perPart = new Map();
      byStudent.set(a.student_id, perPart);
    }
    perPart.set(a.part_id, answersByAttempt.get(a.id) ?? []);
  }

  const levelBooks = books.map((b) => ({
    level: b.level,
    partIds: (partsByBook.get(b.id) ?? []).map((p) => p.id),
  }));

  return students.map((student) => {
    const perPart = byStudent.get(student.id) ?? new Map<string, Answer[]>();

    const statusById = new Map<string, PartStatus>();
    for (const p of parts) {
      statusById.set(
        p.id,
        computePartStatus(questionsByPart.get(p.id) ?? [], perPart.get(p.id) ?? []),
      );
    }

    const unlockedThrough = unlockedThroughLevel(levelBooks, student.startLevel, statusById);

    const rows = books
      .filter((b) => isLevelUnlocked(b.level, unlockedThrough))
      .map((book) => {
        const bookParts = partsByBook.get(book.id) ?? [];
        const completed: { score: number }[] = [];
        for (const p of bookParts) {
          if (statusById.get(p.id) !== "completed") continue;
          completed.push({
            score: partScore(questionsByPart.get(p.id) ?? [], perPart.get(p.id) ?? []),
          });
        }
        return { book, progress: computeBookProgress(bookParts.length, completed) };
      });

    return { student, unlockedThrough, books: rows };
  });
}

# Оқу сауаттылығы — платформа чтения

Next.js + Supabase. Ученики читают книги в Telegram Mini App и проходят тесты,
учитель управляет книгами и проверяет открытые ответы.

## Уровни

Уровень — это одна книга. Уровни идут по порядку: следующий открывается, когда
ученик прошёл все части предыдущего. У каждого ученика есть **стартовый уровень**
(`students.start_level`): уровни не выше него открыты сразу. Учитель меняет его
на `/teacher/students`.

Уровень книги — `books.level`, значение уникально. Учитель назначает его на
странице книги или стрелками в списке книг; при выборе занятого уровня книги
меняются местами.
