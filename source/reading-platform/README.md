# Оқу сауаттылығы — платформа чтения

Next.js + Supabase. Ученики читают книги в Telegram Mini App и проходят тесты,
учитель управляет книгами и проверяет открытые ответы.

## Уровни

Уровень — это одна книга. Уровни идут по порядку: следующий открывается, когда
ученик прошёл все части предыдущего. Все ученики начинают с первого уровня.

У каждого ученика есть **стартовый уровень** (`students.start_level`, по
умолчанию 1): уровни не выше него открыты сразу. Учитель меняет его на
`/teacher/students` — так можно открыть ученику уровень, не заставляя проходить
предыдущие. Прогресс хранится по частям и не зависит от стартового уровня:
уже пройденные части остаются пройденными.

Уровень книги — `books.level`, значение уникально. Учитель назначает его на
странице книги или стрелками в списке книг; при выборе занятого уровня книги
меняются местами.

## Запуск

```bash
npm install
cp .env.local.example .env.local   # заполнить ключи Supabase и токен бота
npm run dev
```

## Проверки

```bash
npm test        # vitest
npm run lint
npm run build
```

## Миграции

SQL из `supabase/migrations/` применяется вручную через SQL Editor в панели
Supabase, по порядку номеров.

Колонки `books.grade` и `students.grade` остались от прежней модели «классов».
Код их не читает и не пишет; удалять их решено не надо — лежат как есть.

Проверить, что миграция уровней применена:

```bash
node --env-file=.env.local scripts/check-levels.mjs
```

Развёртывание описано в `DEPLOY.md`.
