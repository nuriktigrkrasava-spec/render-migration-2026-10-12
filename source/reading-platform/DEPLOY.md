# Запуск платформы — пошаговая инструкция

Эта инструкция рассчитана на человека без опыта в программировании. Все шаги — это
клики в браузере и копирование готового текста. Делайте по порядку.

Итог: учитель заходит на сайт `https://ваш-домен/teacher`, а ученики открывают
Mini App прямо в Telegram.

Понадобятся три бесплатных аккаунта: **Telegram** (уже есть), **Supabase** (база
данных) и **Vercel** (хостинг). И аккаунт **GitHub**, чтобы выложить туда код.

---

## Шаг 1. Создать бота в Telegram (5 минут)

1. В Telegram откройте **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username бота (заканчивается на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Сохраните его — это
   `TELEGRAM_BOT_TOKEN`. Никому не показывайте.

Mini App-ссылку настроим в Шаге 6, когда у сайта появится адрес.

---

## Шаг 2. Создать базу данных в Supabase (10 минут)

1. Зайдите на https://supabase.com → войдите через GitHub → **New project**.
2. Назовите проект, придумайте **пароль базы** (сохраните), выберите ближайший регион,
   нажмите **Create new project**. Подождите 1–2 минуты, пока создаётся.
3. Слева откройте **SQL Editor** → **New query**.
4. Откройте в этом проекте файл `supabase/migrations/0001_initial_schema.sql`,
   скопируйте **весь** его текст, вставьте в SQL Editor и нажмите **Run**.
   Должно появиться «Success». Это создаст все таблицы.
5. Слева **Project Settings → API**. Скопируйте и сохраните:
   - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`;
   - **anon public** ключ → `NEXT_PUBLIC_SUPABASE_ANON_KEY`;
   - **service_role** ключ (нажмите «Reveal») → `SUPABASE_SERVICE_ROLE_KEY`.
     Этот ключ секретный — он только для сервера, не публикуйте.

### Добавить себя как ученика для теста (по желанию)
Чтобы проверить Mini App на себе, нужно знать свой **Telegram ID**: напишите боту
**@userinfobot** — он пришлёт ваш числовой id. Позже учитель сможет выдавать доступы;
сам ученик заводится автоматически при первом входе в Mini App.

---

## Шаг 3. Выложить код на GitHub (10 минут)

Если код уже у вас на компьютере в этой папке:
1. Создайте аккаунт на https://github.com и новый **пустой** репозиторий (Private).
2. GitHub покажет команды вида «…or push an existing repository». Их нужно выполнить
   в терминале в папке проекта. Если не уверены — попросите помощника (или меня в
   следующий раз) выполнить:
   ```
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git branch -M main
   git push -u origin main
   ```
> Подсказка: чтобы выполнить команду прямо в этом чате, напишите её с `!` в начале строки.

---

## Шаг 4. Развернуть на Vercel (10 минут)

1. Зайдите на https://vercel.com → войдите через GitHub → **Add New… → Project**.
2. Выберите ваш репозиторий → **Import**.
3. Framework определится как **Next.js** автоматически — ничего не меняйте.
4. Откройте **Environment Variables** и добавьте 5 переменных (имя → значение):
   - `NEXT_PUBLIC_SUPABASE_URL` → Project URL из Шага 2
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` → anon ключ
   - `SUPABASE_SERVICE_ROLE_KEY` → service_role ключ
   - `TELEGRAM_BOT_TOKEN` → токен бота из Шага 1
   - `TEACHER_PASSWORD` → придумайте надёжный пароль учителя (им вы будете входить в панель)
5. Нажмите **Deploy**. Через 1–2 минуты получите адрес вида
   `https://ваш-проект.vercel.app`. Это адрес платформы.

---

## Шаг 5. Проверить панель учителя

1. Откройте `https://ваш-проект.vercel.app/teacher`.
2. Введите пароль из `TEACHER_PASSWORD`.
3. Создайте книгу → добавьте часть с текстом → добавьте вопросы. Всё должно сохраняться
   (данные уходят в базу Supabase). Если видите ошибку — чаще всего не так скопирована
   одна из переменных окружения; проверьте Шаг 4.

---

## Шаг 6. Подключить Mini App к боту

1. В Telegram снова откройте **@BotFather**.
2. `/newapp` → выберите вашего бота.
3. Заполните название, описание, загрузите картинку (640×360).
4. **Web App URL** укажите: `https://ваш-проект.vercel.app/app`
5. BotFather даст ссылку на Mini App. Также можно настроить кнопку меню:
   `/mybots` → ваш бот → **Bot Settings → Menu Button → Edit menu button URL** →
   тот же адрес `https://ваш-проект.vercel.app/app`.
6. Откройте бота в Telegram, нажмите кнопку меню — откроется Mini App. При первом входе
   вы автоматически появитесь как ученик. Чтобы увидеть книгу — в панели учителя выдайте
   себе (этому ученику) доступ к книге.

---

## Готово

- Учитель: `https://ваш-проект.vercel.app/teacher`
- Ученики: кнопка меню вашего бота в Telegram.

### Частые вопросы
- **Ученик не видит книг.** Учитель должен выдать доступ: панель → Ученики → выбрать
  книгу → выдать. Ученик появляется в списке только после первого входа в Mini App.
- **«TEACHER_PASSWORD is not set» или ошибка базы.** Перепроверьте переменные окружения
  в Vercel (Settings → Environment Variables), затем **Redeploy**.
- **Поменяли переменные — не применилось.** В Vercel после изменения переменных нужно
  нажать **Redeploy** (Deployments → … → Redeploy).
- **Сменить пароль учителя.** Поменяйте `TEACHER_PASSWORD` в Vercel и сделайте Redeploy.

### Сколько это стоит
На старте — бесплатно: и Supabase, и Vercel имеют бесплатные тарифы, которых хватает
для одного учителя и его учеников. Платно станет только при большом росте.
